# CAU 校园通

中国农业大学（CAU）的课表 / 考试 / 成绩 / 公告客户端。两种装法，**同一套界面**：

- **APK（推荐）**：装在手机上直接用。登录教务、抓页面、解析全在手机里完成，
  不需要电脑，凭据用 Android Keystore 加密后只存本机。
- **网页版**：电脑跑一个本地服务，手机浏览器打开局域网地址；数据由本地服务替你登录
  `newjw.cau.edu.cn/jsxsd` 抓取，凭据用 Windows DPAPI 加密后只存本机。

只读客户端：不选课、不评教、不代交作业，数据只在你自己的设备上。

## 现在能做什么

- **课表**：当前学期 6 个大节 × 7 天，周视图 / 日视图，左右翻周，点课程看教师、教室、周次、节次；可隐藏整门课。
- **学业**：考试（按学期切，带倒计时）、成绩（按学期分组、等级/百分制）、学分（按已出成绩统计）。
- **今日概览**：课表页顶部，下节课倒计时 / 正在上第几节 / 考试倒计时，纯本地计算。
- **公告**：学校主页「通知公告」+ 本科生院首页，翻 6 页合并去重；默认过滤招聘/招租/招标这类噪音，列表底部会写明「已隐藏 N 条」，点一下可以看全部。点一条打开原文。
- **我的**：绑定、同步、学期设置（开学日期 / 总周数）、上课时间、解除绑定。
- **离线**：同步一次后课表/成绩/考试存 `localStorage`，断网也能看；公告缓存 30 分钟。

## 装到手机上（APK）

在仓库顶部的 **Releases（发行版）** 页下载最新的 `caucampus-x.y.z.apk` 装上即可
（包名 `com.hobson.caucampus`，最低 Android 6）。APK 不随仓库分发，`*.apk` 已写进
`.gitignore`，仓库里只有源码；要自己出包见下面「自己打 APK」。

Releases 页打不开或下载报 404，通常是仓库为私有、你还不在协作者名单里，
需要仓库拥有者在 Settings → Collaborators 里加人。

**前提：教务系统只在校内网开放**（`newjw.cau.edu.cn` 解析到 `10.200.x.x`，是校内地址）。
手机连校园网、或者先连学校 VPN 再开 App；不在校内时只能看已经同步下来的课表/成绩。

它是个 WebView 壳：页面还是 `web/` 那一套，`web/localapi.js` 在没有 Python 的
环境里把 `bridge.py` 的 `/api/*` 顶替掉 —— 界面代码一行没改，所以两边看到的东西
永远一样。

### 自己打 APK

不需要 Android Studio，也不用 Gradle，但需要一套 Android 命令行工具
（JDK 17、build-tools 34、platform 33）：

```bash
python android/build_apk.py                # 产物在 android/dist/，并复制一份到项目根目录
python android/build_apk.py --clean        # 先清中间产物
CAU_SDK=<工具目录> python android/build_apk.py   # 工具不在约定位置时用环境变量指过去
```

不设 `CAU_SDK` 时，脚本默认在仓库上一级的 `_lab/out/sdk/` 里找；两处都没有会停下并
提示怎么指。签名用的 keystore 同样不在仓库里（在 SDK 目录同级的 `keystore/` 下），
换机器打包要先有自己的 keystore，否则会卡在缺文件检查那一步。

图标也是脚本画的，改配色/换字只需改常量：

```bash
python android/tools/make_icons.py
```

## 网页版怎么跑

双击 **`启动.bat`**。它会：

1. 挑一个 Python 启动 `bridge.py`，顺序是：`env.local.bat` 里的覆盖 → 项目 `.venv` →
   系统 `python`；
2. 自动打开 `http://127.0.0.1:8790/?k=...`；
3. 在「我的」→「绑定教务账号」里填学号密码，登录并同步。

手机访问：电脑和手机连同一个 Wi-Fi，用启动窗口打印的
`http://<电脑IP>:8790/?k=...` 打开。校园网如果开了客户端隔离，手机可能连不上，
用电脑热点最省事。

命令行也可以：

```bash
python bridge.py --port 8790
python bridge.py --no-browser
```

本机要用特定的解释器或环境变量，就在项目根目录建一个 `env.local.bat`
（已写进 `.gitignore`，不会被提交，也不会影响别人）：

```bat
@echo off
set "PY=<你自己的>\\.venv\Scripts\python.exe"
```

## 数据来源

| 数据 | 来源 | 说明 |
| --- | --- | --- |
| 课表 / 成绩 / 考试 / 学期 | `newjw.cau.edu.cn/jsxsd`（强智） | 只读，不选课、不评教 |
| 公告（公开） | `www.cau.edu.cn/tzgg/`、`jwc.cau.edu.cn` 首页通知块 | 公开页面，不需要登录 |
| 校内通知 | `one.cau.edu.cn` 综合服务平台 | **要登录**（统一身份认证）。App 里点「校内通知」用应用内 WebView 打开，登录一次记住；页面加载完会注入脚本把通知列表抠出来存本机，公告页顶部直接显示 |

登录方式：先取 `POST /Logon.do?method=logon&flag=sess` 返回的 `scode#sxh`，
把 `学号%%%密码` 的前 20 个字符按 `sxh` 插入 `scode`，再提交 `encoded`。
普通登录没有验证码；反复失败会触发验证码，程序只尝试一次就停。

## 隐私

- 学号密码用 Windows DPAPI 加密，存 `%LOCALAPPDATA%\CAUCampus\account.bin`；
  只有当前 Windows 账户能解开，拷走文件也没用。
- 访问口令存 `%LOCALAPPDATA%\CAUCampus\token.txt`，只用于局域网内访问本地服务。
- 没有统计、没有上报、不经过任何第三方服务器。
- `_probe/` 里有探测时保存的 HTML，包含姓名、学号、课程、成绩；已写进
  `.gitignore`，**不要把这个目录发给别人**。
- 仓库里的代码与文档不含使用者个人信息：账号、姓名、学号一律不落仓库，
  `env.local.bat` 这类本机路径覆盖也已写进 `.gitignore`，分享或开源前不用再手改。

## 文件

| 文件 | 作用 |
| --- | --- |
| `bridge.py` | 本地服务：HTTP、DPAPI、静态页面、API |
| `cau_jw.py` | 强智教务客户端与解析器（登录、课表、成绩、考试、学期） |
| `notice_cau.py` | 学校通知公告抓取 |
| `web/` | 手机端界面（纯原生 JS，无框架、无构建） |
| `web/localapi.js` | App 内的「本地服务」：接住 `/api/*`，用原生 HTTP + 正则解析顶替 bridge.py。网页版里它什么都不做 |
| `android/` | APK 的壳：`MainActivity`（发 assets、返回键）、`NativeBridge`（HTTP + 凭据）、`CredStore`（Keystore 加密）、`build_apk.py` |
| `RELEASE-NOTES.md` | 每个版本的更新内容，打包脚本会读本版本那一节（**一条一行，别折行**，否则脚本会报错并跳过清单更新） |
| `version.json` | 当前 APK 的版本 / 大小 / sha256，打包时按真实包自动写 |
| `probe_cau.py` | 第一次用的接口探测脚本（已经跑过，可留作排查） |
| `启动.bat` | 一键启动 |
| `env.local.bat` | 本机解释器/环境覆盖，不提交 |
| `_probe/` | 探测产物，含个人数据，不提交 |

## 已知限制

- 课表目前只看**当前学期**；历史学期可以在考试页切，但课表还没做历史切换。
- 考试安排依赖教务系统是否已经发布；没发布时显示「这学期还没排考」，不是「没有考试」。历史学期可能查不到，教务系统看起来只保留当前学期的考试。
- 学籍信息只从教务首页取姓名/学号；没有单独的学籍页。
- 开学日期是按学期名推算的（秋季 9/1、春季 2/20、夏季 7/1 之后最近的周一），
  和学校校历可能差一周；在「我的 → 学期设置」里改。
- **强智教务是会话独占的**：App 登录可能把浏览器里的教务挤下线，反之亦然。
  这是学校系统的行为，不是本软件在踢人。
- APK 新版本发到仓库的 Releases 页；App 内还没有「检查更新」，要手动去 Releases 下载装。
- 公告原文在**系统浏览器**里打开（不在 App 内），因为原文里有附件和外链。
- 没有空教室、智慧门户/一卡通、学习通、直饮水；这些要等核心稳定后再逐个接。

## 只读声明

本软件不包含选课、评教、提交作业、签到、绕过验证码等写操作。
它只是把你自己在教务系统里能看到的数据，换一种更适合手机的方式展示。
